Excel Data Analysis Project

Описание проекта

В данном репозитории представлены выполненные задания по анализу данных с использованием Microsoft Excel.

Выполненные задания

1. Анализ товарооборота по территориям

Объединение данных из нескольких листов.

Создание сводных таблиц по неделям и территориям.

Анализ доли территорий в общем товарообороте.

Определение ТОП-3 территорий.

Визуализация понедельной динамики товарооборота.

2. Excel Assignment

Выполнение заданий на трёх листах Excel.

Работа с данными, формулами и аналитическими расчётами.
